## Description

Refs #53

`run_eiffel_test_matrix.ps1` loaded MSVC only for Finalized lanes. A Workbench lane also runs `finish_freezing`, which with `ISE_C_COMPILER=msc_vc140` needs `cl`/`link`. Now MSVC is also loaded when `ISE_C_COMPILER` is `msc*`; with the default mingw backend nothing changes.

| `-AssertionMode Off -BuildMode Workbench`, no MSVC loaded | Before | After |
|---|---|---|
| `ISE_C_COMPILER=msc_vc140` | `finish_freezing failed`, exit 1 | MSVC loaded, `xpact Eiffel test matrix: ok`, exit 0 |
| `ISE_C_COMPILER` not set (mingw) | ok | ok, no MSVC import |

Found while testing, not changed here (details in the report):
- The `msc_vc140` EiffelBase precompile was missing on the student PC (`LNK1181 ... msc_vc140\precomp.lib`); rebuilt, steps in the setup guide.
- Started outside the repository root, the script runs a stale `xpact_tests.exe` and reports `ok` (false pass). Will be filed separately.
