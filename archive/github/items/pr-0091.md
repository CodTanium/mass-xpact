## What changed

Both xpact pipelines now expose `EMAIL_RECIPIENTS`. It starts empty, retains the last submitted value for later builds, and can be cleared to disable notifications. A final `post cleanup` step sends one email for `FAILURE` or `UNSTABLE`, with the build result and build/console links. Mail delivery failures preserve the original build result; cancellation propagates. Successful, aborted, and not-built results do not send email.

Documentation explains where to enter recipients and configure SMTP. A separate prerequisite commit fixes two existing Groovy string escapes in the all-tests Sonar block, which prevented that complete Jenkinsfile from parsing.
