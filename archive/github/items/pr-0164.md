## What changed
- 0b0f5ee Include an external parameter entity's text in an entity literal (`src/xp_parser.e`, `src/xp_native_parser.e`, `src/xp_native_callback_handler.e`, new `src/xp_literal_check_handler.e`)
- eaf596b Add the #159 report and update the plan

A parameter entity referenced inside an entity value is "included in literal" (XML 1.0 §4.4.5). Through the DLL, the literal-mode child parsed the file as declarations (reported and merged into the parent) and gave no text back, so the value stayed empty. Now:
- the child keeps the text after the text declaration and still **checks** it like DTD text, as Expat does, through a new `XP_LITERAL_CHECK_HANDLER` (declarations and content silent; the text declaration and a stop request still reach the application);
- `%` references in the text are expanded as in any entity value;
- the native parser does not merge a literal child's declarations; the callback returns the text and replays it on a re-parse.
