## Problem
Jenkins on `main` @ `9e1747d` (2026-10-23) stopped at **Build Eiffel-Backed DLL**: `Cannot find Eiffel runtime include directory.` Every later stage was skipped. Full log: `reports/issue-0073/jenkins-log-2026-10-23.txt`.

## Cause (confirmed)
Our fixes for #2 (`9eb18bd`) and #10 (`20e6bc3`) **replaced** the fallback `C:\El2502E` (EiffelStudio 25.02 Enterprise, the Jenkins machine) with the student PC's 25.12 Standard path, instead of adding it.

## Fix
`Get-IseInclude` in `scripts/build_native_eiffel.ps1` and `scripts/run_native_runtime_smoke.ps1` searches: `ISE_EIFFEL` → `C:\El2502E` → EiffelStudio 25.12 Standard → the EiffelStudio whose `ec` is on `PATH`. The error lists the folders searched.

All other student changes to `scripts/`, `ci/` and `.ecf` since `fee611a` were checked for machine-specific values (table in the report). One more was found: the forced `ISE_C_COMPILER=msc_vc140`, filed separately as #74.
