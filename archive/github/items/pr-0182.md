## Description

Refs #179

## Problem
Without `-XpactLibrary`, `scripts/run_libexpat_adapter.ps1 -Mode NativeSuite` linked Expat's C tests against `build\native\xpact.lib`, the C bridge **without** the Eiffel parser. Every test then failed with error 44, "Eiffel parser bridge is not installed". Without `-SkipNativeBuild` it even built that bridge first, so the documented command `-Mode NativeSuite` (`docs/phase-1.md`) could not pass. Found by A04 (#168). Jenkins is not affected: it passes `-XpactLibrary build\native-eiffel\xpact.lib -SkipNativeBuild`.

## Change
- Default library: `build\native-eiffel\xpact.lib`. The bridge-only build is never picked by itself; with no Eiffel library you get a clear message saying how to build one.
- `-Mode NativeSuite` without `-SkipNativeBuild` builds with `build_native_eiffel.ps1` instead of `build_native.ps1`.
- The log names the library used (`libexpat native suite: xpact library <path>`).
- New regression test: the CMake stand-in records its arguments, and the test checks the library CMake is configured with.
- `adapters/libexpat/README.md`: a paragraph on the default.
