## Description

Ordinary marker strings in `XP_PARSER.parse_markup` were recreated on every dispatch: 909 temporary marker constructions per 100-item catalog document. Cache the ten marker literals with Eiffel `once` strings while preserving the original classification order, diagnostics and contracts. This retains the catalog improvement without the earlier byte-dispatch prototype's text-heavy regression.

Same-computer, fresh baseline/candidate finalized builds against `3a5551d`, six alternating AB/BA pairs per workload:

| Workload | Windows MSVC throughput change | WSL2 GCC throughput change |
|---|---:|---:|
| Catalog | +31.3% | +29.6% |
| Text-heavy | −0.7% | +0.3% |
| Attribute-heavy | +0.6% | +0.1% |
| PubMed extract | −1.5% | +0.8% |
| Unicode stylesheet | +13.5% | +9.0% |
| Legislation | −0.3% | +0.3% |

Both text-heavy medians meet the preselected 2% regression budget. Assertion-enabled catalog throughput improves by 6.7% on MSVC and 4.1% on GCC. Small changes remain within observed pair variation; the real corpora show that marker reuse does not remove the remaining parsing bottlenecks.

Adds a reusable paired benchmark driver with common iteration calibration, child-result validation, executable/input hashes and report cleanup after failure. Documents the method and all 84 raw pairs, including outliers, in `docs/tag-dispatch-performance.md` and `benchmarks/results/`.

Validation:

- All 54 Eiffel regression tests pass in each workbench/finalized × assertions off/on lane. New cases verify malformed-prefix diagnostics, callback positions and repeated failure/recovery with DTD state reset.
- Fresh baseline/candidate match on 1,727 applicable W3C cases and 40 directed cases in each finalized assertion mode; 858 cases are excluded by the existing profile. No outcome or diagnostic differences.
- Rebuilt Eiffel-backed Windows DLL passes the native smoke test.
- All 52 Python harness tests pass on Windows; the ten new paired-driver tests also pass on WSL Python 3.8. Includes direct and hard-link input/output collision checks. Adds the new suite to GitHub Actions.

The cached strings are bounded, runtime-managed constants. Prefix helpers only read them and retain no parser or document references, so reset and failure add no cache invalidation or resource cleanup path.
