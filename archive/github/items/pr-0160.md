- bca7d9d Add the #154 report, the W3C output test and the plan update

An external DTD, parameter entity or general entity is read by a child parser. Parent and child exchanged only the **entity** tables, never the attribute declarations, so `<!ATTLIST>` defaults from an external file were lost and "the first declaration wins" broke. The attribute table now travels the same way (import, merge, replay snapshot), keeping the first binding of each attribute.
