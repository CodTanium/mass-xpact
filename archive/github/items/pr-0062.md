## Description

Refs #45

B01. Both Eiffel test runners (`XP_TEST_ROOT`, `XP_NATIVE_RUNTIME_SMOKE`) ended with `check ...: False end`, which only fires when assertions are compiled in. With assertions off, a failing test printed `FAIL` and the exe exited 0, so `run_eiffel_test_matrix.ps1`, `run_native_runtime_smoke.ps1` and Jenkins said ok. Now they print `... FAILED` and call `{EXCEPTIONS}.die (1)`.

With a temporary deliberately failing assert (not committed; B02 adds a permanent switchable one):

| Lane | Before | After |
|---|---|---|
| Off / Workbench, Off / Finalized | `FAIL` printed, `matrix: ok`, **exit 0** | `FAILED`, exit 1 |
| On / Workbench, On / Finalized (`-keep`) | - | exit 1 |
| native smoke Off | `FAIL` printed, **exit 0** | exit 1 |
| native smoke On | - | exit 1 |

Without it: assertions-off lanes and both native smoke runs `ok`, exit 0; assertions-on lanes exit 1 on the real B03 failure (#3).
