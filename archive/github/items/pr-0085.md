## Description

Jenkins rejected the Windows libexpat gate on native crashes, unexpected compatibility failures, and parsing timeouts. The rebuilt DLL now completes all 399 upstream Expat 2.8.1 tests: 361 pass and 38 match the existing allocator-injection expectations. The Windows PowerShell 5.1 gate returns 0; the expected-failure list and timeout limits are unchanged.

The fixes cover native buffer/reset/error lifecycles, strong ownership of Eiffel parser handles, caller-owned content models, partial encodings, callback positions and literal default output, and external-child declarations across prefix replay. Iterative entity/model traversal and bounded token scans remove stack and repeated-scanning failures. Silent completed DTDs can be reused with source comparison, accounting restoration, and invalidation; external replay retains detached declaration deltas instead of child parsers.

The adapter now applies each test's actual deferral configuration to parser creation and reset. Native names use the approved 512 KiB ceiling and native tokens stay within the existing 10 MiB input budget. Document depth, attribute, nested-expansion, and expansion-byte limits remain bounded; generic Eiffel name/token defaults and fifth-edition name rules are preserved.

- 13 adapter and 28 W3C-runner Python regressions pass; Windows public/bridge ABI smokes pass.
