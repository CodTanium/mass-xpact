## Description

Jenkins builds 67 and 68 crash before finishing the native suite. Minicheck uses longjmp for assertions, including assertions inside C callbacks entered from Eiffel. Controlled sequences showed that a callback failure could leave invalid Eiffel GC roots for a later parser setup; correcting the Jenkins result classification exposed this existing crash.

Run each registered Windows test in a fresh child process. Assertion failures print the named test and fixture phase, flush diagnostics, and exit the child immediately. Passing tests still run all 12 chunk-size/deferral combinations; a failing named test stops at its first assertion. The parent collects results and continues with a fresh process. Capture all three upstream registration APIs and reconcile their metadata against the enabled upstream suite.

Use an atomically assigned Windows job to release the active child when the parent is cancelled. Bound child execution at 120 seconds by default and the CTest suite at 1800 seconds. Confirm termination before continuing after a timeout; abort without a completed-run summary if cleanup cannot be confirmed. Keep crashes, timeouts, and unlisted failures fatal. Stream CTest output to Jenkins while retaining the saved log. Non-Windows builds retain the original runner.

Add native lifecycle regression tests and run them with the existing adapter tests in both Jenkins pipelines. Document the fail-fast context coverage and current parity limits.

Validation:
- Built the real Expat 2.8.1 suite with VS2022/MSVC against the Jenkins workspace library; the registry covers all 399 enabled tests.
- The real test_invalid_foreign_dtd -> test_attributes sequence now completes with one assertion failure and one pass, without a process exception.
- Real CTest with an expected allocator failure plus a passing test returns CTest 8 and a validated PowerShell wrapper status 0.
- All 12 adapter/isolation regression tests passed. Native tests cover callback exit, later-test state, setup/teardown phases, real access violations, timeouts, cancellation, and child release. Native tests passed again after cleanup changes.
- A deliberately bounded diagnostic sweep (five seconds per child) completed all 399 named tests in 87 seconds: 267 passed, 121 assertions, 11 timeouts, zero process exceptions. This short diagnostic limit is distinct from the configured 120-second gate.
- git diff --check passed.

The full native suite still has unlisted compatibility failures. This change contains the harness crash and provides complete named results; it does not establish a passing Jenkins pipeline or change the expected-failure patterns.
