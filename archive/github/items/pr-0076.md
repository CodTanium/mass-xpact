## Description

## Problem
`scripts/build_native_eiffel.ps1` (since #7) and `scripts/run_native_runtime_smoke.ps1` (since #10) **always** set `ISE_C_COMPILER=msc_vc140`, overriding a machine that already builds with another MSVC backend (e.g. `msc`). Before the student fixes, Jenkins used its own backend. Not seen failing yet (Jenkins stops earlier, #73); found while checking every student build change against the Jenkins machine.

## Fix
Keep an existing `msc*` value; switch only an unset or non-MSVC backend to `msc_vc140`. The student PC (unset) still gets `msc_vc140`.
