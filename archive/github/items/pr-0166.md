- 5a7f362 Keep delivered callbacks delivered across XML_Parse calls (`src/xp_native_parser.e`, 1 line)
- 6d0db96 Add the #165 report, the W3C-in-pieces test and the plan update

The DLL re-parses its whole buffer on every `XML_Parse` call and skips the callbacks it already delivered. After a non-final call, the count of delivered callbacks was set to what *this* re-parse produced. A call that re-parsed less (e.g. only up to an unfinished DOCTYPE) lowered the count, so the next call delivered `startdoctype`, `entitydecl`, … again. The count can no longer go down.

Smallest trigger, 4 pieces: `<?xml version="1.0"?` · `><!DOCTYPE d [<!ENTITY e "v">` · `]` · `><d/>` (call 4 repeated callbacks 2 and 3).
