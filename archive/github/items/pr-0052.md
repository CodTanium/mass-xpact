## Description

Refs #51

`vcvars64.bat` calls `vswhere.exe` by name; without `C:\Program Files (x86)\Microsoft Visual Studio\Installer` on `PATH` it prints `'vswhere.exe' is not recognized` to stderr, and Windows PowerShell 5.1 stops `import_msvc_environment.ps1` when the output is captured. The script now appends that folder to `PATH` inside the `cmd.exe` call. The manual line in the setup guide is removed.

| Run | Before | After |
|---|---|---|
| Load MSVC with output captured, no Installer folder on `PATH` | `NativeCommandError`, exit 1 | loaded, `cl.exe` found, exit 0 |
| Load three times in one session | - | runs 2-3 skip ("already loaded"), `PATH` length unchanged (#4 still holds) |
