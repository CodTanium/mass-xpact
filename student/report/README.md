# Report and handover

Weeks 8–10. The guide's minimum outcome is a reproducible baseline, an agreed
regression set, one reviewed contribution or demonstrated blocker, and a clear
handover.

| File | Content |
|---|---|
| `report.md` | Question, background, method, results, limitations and next steps. Include commands and input identifiers so another person can check the work. |
| `demonstration.md` | What is shown in the final demonstration, and the exact commands |
| `setup-guide.md` | How another developer reproduces the builds and runs the tests |
| `follow-up.md` | Open findings and suggested next tasks, each linked to its issue |
