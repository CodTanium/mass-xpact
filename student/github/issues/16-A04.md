## Goal
Verify the actual library loaded by tests, benchmarks and packaged examples. Test both workbench and finalized assertions-enabled builds and every other configuration that is still supported.

## Why
Student guide, task register A04. A comparison is only meaningful if it is known which build was measured.

## Done when
- [ ] For each runner: the path and hash of the DLL actually loaded (e.g. Process Monitor, `Get-Process -Module`, or a log line)
- [ ] Table: configuration -> expected library -> observed library
- [ ] Mismatches filed as findings; results in `student/results/A04-loaded-library/`
- [ ] Re-run the C# P/Invoke smoke test against `build\native-eiffel\xpact.dll`

## Evidence / notes
Error report, section 4.6: the bridge-only `build\native\xpact.dll` (from `build_native.ps1`) returns error 44 "Eiffel parser bridge is not installed" from a C# `XML_Parse` call. The Eiffel-backed DLL is in `build\native-eiffel\`. Make sure no consumer loads the bridge-only DLL by mistake.
