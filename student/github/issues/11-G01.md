## Goal
Build a portable corpus manifest with sources, versions, hashes, dependencies and expectations. Start with a reviewed subset of 50–100 applicable W3C XML cases.

## Why
Student guide, task register G01 and the week 4 plan ("An input matrix with reviewed expected outcomes").

## Done when
- [ ] A manifest (e.g. `student/results/G01-corpus/manifest.tsv`) with case ID, path, sha256, type, expected outcome and dependencies
- [ ] 50–100 cases selected **with the supervisor**: text-, tag- and attribute-heavy, namespaces, encodings, DTD/entities
- [ ] Cases that need external entities or XML 1.1 are marked, not silently counted
- [ ] Expected outcomes reviewed (see "Read the expected outcome correctly" in the guide)
